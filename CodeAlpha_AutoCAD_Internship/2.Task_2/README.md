## Part Description
**0.5" (1/2") Class 150 Blind Flange, Flat Face**

A blind flange is a solid disc used to seal off the end of a pipeline, valve, or pressure vessel opening — no bore through the center, unlike a weld-neck or slip-on flange.

## Views Provided
- **Front view** — circular face showing outer diameter, bolt circle, and bolt holes.
- **Side (edge) view** — flange thickness.
- **Isometric view** — 3D pictorial for visual reference.

## Key Dimensions
| Feature | Drawing | ASME B16.5 Class 150, NPS 1/2" standard |
|---|---|---|
| Outer diameter | Ø 3.50" | 3.50" ✅ match |
| Bolt circle diameter | Ø 2.38" | 2.38" ✅ match |
| Bolt holes | 4× Ø 0.62" | 4× Ø 0.63" ✅ match |
| Flange thickness | 0.38" | 0.44" (min.) ⚠️ slightly thinner than standard |

Outer diameter, bolt circle, and bolt hole pattern match the published ASME B16.5 Table 1.1-1 values for a 1/2" Class 150 blind flange. The drawn thickness (0.38") is below the standard's minimum (0.44") — worth a note if this is graded against the real spec, though it doesn't affect the drafting/dimensioning technique being assessed.

## Drafting Notes
- Dimensions follow standard ANSI/ASME dimensioning conventions (diameter symbol, "4X" hole callout, bolt circle reference).
- Centerlines shown for the bolt circle and hole pattern per drafting standard.
- Isometric view included for quick visual identification alongside the orthographic views.
